    Elegí la carpeta de un juicio con PDF, DOCX y TXT. La aplicación indexa el texto en tu computadora y, cuando le pedís una tarea, envía a la IA únicamente el contenido necesario para resolverla.

    Control de plazos

    El cómputo es una ayuda: confirmá siempre el vencimiento contra el código procesal aplicable, el calendario judicial y la forma de notificación. Cargá feriados y ferias en Ajustes.

    Nuevo plazo

    Plazos cargados

    Búsqueda documental

    Búsqueda local e instantánea (no usa IA). Para una respuesta redactada con citas, usá Preguntar al expediente en el Asistente.

    Ajustes

    Confidencialidad

    Al ejecutar una tarea, el texto de los documentos seleccionados se envía a la API de Anthropic para ser procesado. Los expedientes contienen datos personales y secreto profesional: antes de usar esta herramienta con casos reales, verificá los términos de tratamiento de datos de tu cuenta de API y las obligaciones de reserva que correspondan, y considerá anonimizar a las partes.

    Conexión con la IA

    Calendario judicial

    La app no trae un calendario precargado para no inducir a error: cargá los días según los acuerdos reglamentarios vigentes del tribunal.
